# 案例库总览（框架）

本目录按 **类目分子文件夹**，每个案例一篇 **PDF**。当前为框架，请按需往里添加文件。

## 命名建议

- `01-简短标题.pdf`、`02-…`：便于排序。  
- 或 `YYYY-MM-主题.pdf`：便于按时间归档。

## 单篇 PDF 可包含（自拟）

1. **背景**：要解决什么问题。  
2. **使用的 AI 工具 / 模型**：名称与大致用法。  
3. **提示词或工作流**：步骤化记录（可截图或文字）。  
4. **产出与验证**：结果如何检验（运行、实验、听感、文献对照等）。  
5. **反思**：局限、踩坑、是否需人工复核。
