专业课学习 软件开发 提示词怎么写 安全与诚信

一、AI × 专业课学习

适合场景：理解新概念、把一章书拆成提纲、对照例题讲思路、用你自己的话复述检验是否真懂。

推荐操作步骤

  1. 先自己读一遍课件或教材，标出不懂的名词和推导卡住的地方。
  2. 向 AI 提问时附上章节主题，但不要直接粘贴整本有版权的扫描件；可概括段落大意。
  3. 要求 AI 用类比、分步推导、小例子解释，并让它出题让你回答，再批改。
  4. 把 AI 的解释与教材定义对照；有冲突以教材和课堂为准。

示例提示词（可复制改写）

你是「大二数据结构」助教。我正在学「红黑树插入」，请：
1) 用不超过 200 字说明核心不变量；
2) 分 3 步讲插入后如何修复（不要背代码，讲逻辑）；
3) 给我一道手写推演小题，等我回复后再指出错误。
诚信：若课程禁止 AI 代写作业，请仅用于理解与练习；提交前按老师要求声明使用情况。

二、AI × 软件开发（创作）

适合场景：把模糊需求拆成任务、生成脚手架代码、解释报错、写单测与 README、做 Code Review 风格的建议。

推荐操作步骤

  1. 写清目标用户、输入输出、技术栈限制（例如：必须 Python 3.11、不用数据库）。
  2. 让 AI 先出文件/模块结构与接口，再逐文件实现；每步运行或测试后再继续。
  3. 粘贴完整报错栈与相关代码片段；说明「你试过什么、结果如何」。
  4. 要求输出包含如何运行、依赖、已知限制，便于交接与复习。

示例提示词（可复制改写）

我要做一个命令行待办工具，语言 Python 3.11，数据存本地 JSON。
请先列出建议的目录结构和每个文件的职责，不要写代码。
我确认后再让你实现 `add` / `list` / `done` 三个子命令。

三、提示词怎么写（通用结构）

记住四个字：角 · 务 · 束 · 式

  • 角色：你是谁（助教 / 资深后端 / 代码审查）。
  • 任务：具体要达成什么。
  • 约束：语言、长度、禁止事项、已有代码版本。
  • 输出格式：分点、表格、仅代码块、先提纲后细节等。

四、安全、隐私与验证

  • 勿向模型发送学号、身份证、密钥、内网地址；代码里的密钥用占位符代替。
  • AI 可能编造论文或 API：重要事实请查官方文档或运行验证。
  • 把本页与仓库 README 一起发给同学，便于统一约定使用方式。
