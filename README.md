# AI-InspireFlow

面向同学的 **AI 辅助学习** 与 **AI 辅助创作** 案例库。各类目案例以 **PDF** 形式放在对应文件夹中，便于统一浏览与后续补充。

## 案例类目（PDF）

| 类目 | 目录 | 说明 |
|------|------|------|
| 软件开发案例 | [`cases/software-development/`](./cases/software-development/) | 需求、架构、编码、调试、工具链等 |
| 硬件开发案例 | [`cases/hardware-development/`](./cases/hardware-development/) | 原理图、PCB、嵌入式、调试与量产相关 |
| 音乐创作案例 | [`cases/music-creation/`](./cases/music-creation/) | 作词编曲、音色设计、DAW 与 AI 工具协作 |
| 论文解读案例 | [`cases/paper-interpretation/`](./cases/paper-interpretation/) | 文献结构、方法复现、批判性阅读（注意引用规范） |
| 专业课知识学习案例 | [`cases/course-learning/`](./cases/course-learning/) | 概念拆解、习题思路、知识图谱式复习 |
| 其他案例 | [`cases/other/`](./cases/other/) | 未归入以上类目的补充材料 |

更细的填写说明见 [`cases/README.md`](./cases/README.md)。

## 使用方式

1. 在对应类目文件夹下放入 `.pdf` 文件（建议见各目录内说明）。  
2. 推送到 GitHub 后，在网页上点开 PDF 即可在线预览（视仓库权限与文件大小而定）。  
3. 大文件可考虑 [Git LFS](https://git-lfs.github.com/) 或外链网盘，并在该目录 `README.md` 中写明链接。

## 学术诚信与内容规范

- 作业、考试与论文请遵守学校规定；引用他人工作须规范标注。
