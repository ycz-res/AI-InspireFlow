# AI-InspireFlow

面向同学的 **AI 辅助学习** 与 **AI 辅助创作（编程）** 轻量指南仓库。目标是用清晰步骤说明：如何把 AI 用在专业课理解与作业上，以及如何用它提升写代码、调试与项目交付的效率。

## 如何使用本仓库

| 方式 | 说明 |
|------|------|
| **网页版（推荐）** | 在浏览器中打开 [`index.html`](./index.html)，按版块浏览操作步骤与提示。 |
| **GitHub 在线看** | 将本仓库推送到 GitHub 后，在仓库根目录打开 `index.html` 的 **Raw** 可复制到本地，或使用 [GitHub Pages](https://pages.github.com/) 托管后访问。 |
| **本地阅读** | 克隆或下载仓库后，双击 `index.html` 或用「在浏览器中打开」即可。 |

## 内容概览

1. **AI × 专业课学习**：拆概念、做笔记、做题思路、查漏补缺（注意学术诚信）。  
2. **AI × 软件开发**：需求澄清、技术选型、写代码、改 Bug、写文档与测试。  
3. **通用习惯**：提示词结构、上下文管理、安全与隐私、如何验证 AI 输出。

## 快速操作清单（5 分钟上手）

1. 选一个工具（见下方「常用工具」）。  
2. 用 **角色 + 任务 + 约束 + 输出格式** 写第一条提示（示例见 `index.html`）。  
3. 把 **课程材料 / 报错信息 / 代码片段** 贴进对话（脱敏后再贴）。  
4. 对重要结论 **自己查证**（教材、官方文档、运行结果）。  

## 常用工具（任选）

- **对话类**：ChatGPT、Claude、通义千问、文心一言、Kimi 等。  
- **编程辅助**：GitHub Copilot、Cursor、Codeium 等（多数与教育优惠或试用相关，以官网为准）。  
- **检索与文档**：课程 PDF、教材、官方文档、Stack Overflow。

## 学术诚信与合规

- 作业与考试请 **遵守学校规定**：哪些环节可用 AI、是否需要声明，以课程要求为准。  
- 勿将 **考试原题、未公开答案、他人隐私** 输入模型。  
- AI 生成内容可能 **事实错误**：关键论点务必核对来源。
